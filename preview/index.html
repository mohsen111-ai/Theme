Nyx

A night-sky theme for the Infinix GT 30 Pro: clean minimal moonlit scenes, a smaller set of ink-sketch ones, and painted app icons on a home screen of its own. This is the second look at the style before the full set of 300 gets made.

App icons

Three icon packs, each shown with the same twelve apps. The finished packs cover the apps most phones have and fall back to a hand-drawn tile for anything else.

Wallpapers

About 70% are clean minimal and 30% ink sketch. Tap one to see it full size. Live and Long scenes are moving right now. Long scenes run a 45 second cycle, so give them a moment.

The full set

Every scene is drawn by the same engine, so the full set is mostly new compositions of the same parts: moon, houses, trees, water, weather. Objects and creatures are placed on the surfaces they stand on.
